# Canvas HTML - generated output

Generated by `build_canvas_html.ps1` from `content/*.json`.
**Leave these HTML files alone** - edit the JSON and re-run the build.

Each file is a **body fragment**: open it, copy everything, and paste it into the Canvas HTML editor
(the `</>` button at the bottom-right of the Rich Content Editor).  There are no `<style>` or
`<script>` tags and no external assets, so Canvas will not strip anything.

## Before you publish

Every Page and every Assignment carries one AI-helper button with a placeholder link:

``html
<a href="PASTE_FLINT_URL_HERE" ...>Open the AI Helper</a>
``

Search each file for `PASTE_FLINT_URL_HERE` (flagged by a `<!-- FLINT-LINK -->` comment) and swap in
that lesson's Flint chat URL. There are **two per lesson** - one on the Page, one on the Assignment.

Teacher files open with a red banner.  Keep them in an **unpublished** module.

`front-page.html` additionally has `LINK_*` placeholder hrefs - see the table at the bottom.
